# remote-agent releases (archived)

**remote-agent is now open source. Its source, releases, installer and documentation live at [github.com/Lewin671/remote-agent](https://github.com/Lewin671/remote-agent).**

This repository is archived and receives no new releases.

- **Installed Android app or daemon:** update once more as usual. Version 0.40.0, the last release here, checks the new repository for every later update.
- **New installations:** follow the [README](https://github.com/Lewin671/remote-agent#readme) and the [self-hosting guide](https://github.com/Lewin671/remote-agent/blob/main/docs/self-hosting.md). The installer is `https://raw.githubusercontent.com/Lewin671/remote-agent/main/install.sh`.
- **Issues and security reports:** please open them in the new repository.
